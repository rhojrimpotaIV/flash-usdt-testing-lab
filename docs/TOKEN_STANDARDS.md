# Token Standards

## ERC-20

ERC-20 is a common interface for fungible tokens on Ethereum-compatible
blockchains.

## TRC-20

TRC-20 is a token standard used on the TRON network.

## Testing

Developers can study token balances, transfer functions, events,
transaction receipts, and failure conditions using local blockchain
environments or supported testnets.

A token using either interface is not automatically genuine USDT.
Verify the token contract address using an authoritative source.

3. How to upload everything

On GitHub:

Open your flash-usdt-testing-lab repository.
Select Add file → Create new file.
Enter the filename, such as src/index.js.
Paste the corresponding content.
Commit the file.
Repeat for the other files, creating folders by including / in the filename.

Important: This is a starter project, not a production-ready blockchain application. The simulator does not create real USDT or submit transactions to a blockchain.
